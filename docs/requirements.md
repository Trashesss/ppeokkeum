# 3D 낚시 힐링 광장 — 요구사항

## 1. 방향

| 항목 | 결정 |
|---|---|
| 형태 | 실제 사람들이 쓰는 웹 서비스 (설치 없이 브라우저로 접속) |
| 공간 | 공개 광장 우선, 이후 아는 친구끼리 쓰는 비공개 방 |
| 성격 | 가벼운 게임(도감·희귀도·기록) + 머무는 공간(채팅·앉기·모닥불) |
| 아트 | 저폴리 3D. 무료 에셋을 최대한 쓰고 부족한 것은 직접 제작 |
| 과금 | 기본 무료. 꾸미기 전용 유료 아이템 판매 예정 (낚시 확률·희귀도에 영향 없음) |
| 계정 | 1단계는 게스트만. 상점 오픈 시 소셜 로그인 추가 (결제할 때만 요구) |
| 모바일 | 3단계. 입력은 처음부터 행동 단위로 추상화 |

## 2. 기술 구조

```
[브라우저] Vite + React + React Three Fiber + drei + zustand
     │  WebSocket
[게임 서버] Colyseus (Node.js)
     │   ├─ PlazaRoom: 공개 광장 채널
     │   └─ 같은 Room에 private 옵션 + 초대코드 (2단계)
     ├─ Redis: 다중 프로세스 방 목록 공유, 채팅 rate limit
     └─ PostgreSQL: 플레이어, 도감, 어획 기록, 아이템
[정적 파일] 클라이언트·에셋을 CDN 배포
```

설계 원칙
- 광장과 친구 방은 같은 Room 코드를 쓰고 공개/비공개 옵션으로만 구분한다.
- 물고기 종류·크기·입질 시각은 서버가 정한다. 클라이언트는 입력(던짐·당김)만 보낸다.
- 가까운 플레이어만 고빈도 동기화한다 (Colyseus `StateView`).
- 에셋은 glTF + Draco/meshopt, 텍스처는 KTX2.
- 낚시 규칙(출현표·판정)은 `shared` 패키지의 순수 함수로 두고 클라이언트·서버가 함께 쓴다.

## 3. 기능 명세

### A. 입장과 계정
| ID | 기능 | 완료 조건 |
|---|---|---|
| A1 | 게스트 입장 | 닉네임만 넣고 10초 안에 광장 진입. 기기 토큰으로 진행 유지 |
| A2 | 닉네임 규칙 | 2~12자, 금칙어 차단. 같은 채널에서 겹치면 `#1234` 태그 |
| A3 | 복구 코드 | 설정에서 `TUNA-8K2F-RIVER` 형식 코드 발급. 다른 기기에서 입력하면 진행 이어받기 |
| A4 | 소셜 로그인 (2단계) | 게스트 진행을 계정으로 이전. 결제 시에만 필수 |

### B. 광장과 채널
| ID | 기능 | 완료 조건 |
|---|---|---|
| B1 | 자동 배정 | 자리 남은 채널로 자동 입장. 채널당 최대 40명 |
| B2 | 채널 자동 생성 | 모든 채널이 가득 차면 새 채널 생성 |
| B3 | 채널 이동 | 채널 목록·인원을 보고 이동 |
| B4 | 친구 방 (2단계) | 초대 링크/코드로만 입장. 낚시 규칙은 광장과 동일 |

### C. 이동과 캐릭터
| ID | 기능 | 완료 조건 |
|---|---|---|
| C1 | 이동 | WASD/방향키 + 마우스 3인칭 카메라. 200ms 지연에서도 타인 이동이 부드러움 |
| C2 | 아바타 | 저폴리 캐릭터 1종, 꾸미기 슬롯 장착 |
| C3 | 상호작용 | 벤치·데크 앉기, 모닥불 둘러앉기 |
| C4 | 이모트 | 5~6종, 주변 플레이어에게 보임 |

### D. 낚시
| ID | 기능 | 완료 조건 |
|---|---|---|
| D1 | 낚시 자리 | 물가 구역 진입 시 "낚시하기" 안내. 구역 밖 낚시 불가 (서버 검증) |
| D2 | 캐스팅 | 누른 시간에 비례한 거리. 주변 사람에게 동작·찌가 보임 |
| D3 | 입질 | 3~15초 뒤 찌 흔들림 + 효과음. 1초 안에 반응 |
| D4 | 끌어올리기 | 장력 게이지 미니게임 5~10초. 실패 페널티 없음 |
| D5 | 결과 | 종류·크기·희귀도 표시, 보관/방생. 희귀 이상은 채널 전체 알림 |
| D6 | 출현 조건 | 장소(호수·강·바다) × 시간대(낮·밤) 출현표. 첫 출시 10~15종 |
| D7 | 판정 검증 | 서버가 입질 시각 기록, 비정상적으로 빠르거나 반복되는 성공 거부 |

### E. 수집과 기록
| ID | 기능 | 완료 조건 |
|---|---|---|
| E1 | 도감 | 잡은 종은 채움, 못 잡은 종은 실루엣. 종별 최대 크기. 서버 저장 |
| E2 | 오늘의 어획 게시판 | 광장 오브젝트. 채널에서 오늘 잡힌 큰 물고기 Top 10 |
| E3 | 내 기록 | 총 어획 수, 희귀 어획 수 |
| E4 | 보상 아이템 | 도감 50% 달성 → 찌 스킨, 전설 첫 어획 → 모자 등 |

### F. 소통과 안전 (공개 광장이므로 1단계 필수)
| ID | 기능 | 완료 조건 |
|---|---|---|
| F1 | 채팅 | 말풍선 + 채팅 로그, 최대 100자 |
| F2 | 필터 | 금칙어 마스킹, 링크·연락처 패턴 차단 |
| F3 | 도배 방지 | 3초에 1개. 초과 시 일시 채팅 금지 |
| F4 | 차단 | 차단한 사람의 캐릭터·채팅을 내 화면에서 숨김 |
| F5 | 신고 | 캐릭터 클릭 → 신고. 직전 채팅 로그 함께 저장 |
| F6 | 관리 도구 | 킥, 기간 정지, 영구 정지 (게스트는 토큰 + IP 기준) |

### G. 꾸미기와 상점
- 슬롯: 모자, 상의, 낚싯대 스킨, 찌 스킨, 이모트 (확장: 이름표 테두리, 캐스팅 이펙트)
- 유료 아이템은 외형만 바꾼다.
- 데이터 구조 (1단계부터 이 형태 유지)

```
items       (id, slot, name, source: default | reward | shop, price)
owned_items (player_id, item_id, acquired_at, via)
equipped    (player_id, slot, item_id)
```

- 상점 오픈(2단계) 시: 소셜 로그인, 결제 대행(토스페이먼츠/포트원), 환불 정책, 사업자 등록, 약관·개인정보처리방침.

### H. 분위기
- 낮밤 사이클: 실제 20분 = 게임 하루. 서버 시간 기준으로 모두 같은 하늘
- 물결 셰이더, 반딧불·나뭇잎 파티클, 로파이 BGM, 물소리·새소리. 볼륨 개별 조절
- 날씨(비·안개)는 2단계

### I. 비기능
- 내장 그래픽 노트북 크롬에서 40명이 보일 때 60fps
- 첫 로딩 10초 이내, 에셋 총량 20MB 이하
- 서버 재시작 후에도 도감·기록 유지
